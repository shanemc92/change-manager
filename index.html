About

A builder for IT change requests. Fill in the ten fields, copy the result into whatever change management system you are stuck with, and save the ones you write often as templates. Placeholders written as <name> are picked up automatically and can be filled in across every field at once.

Everything runs in this tab. Templates and the form in progress live in this browser's local storage, so they survive a refresh and never leave the machine. Clearing site data clears them, which is what Save JSON is for.

Importing

the one network call

A template library is a JSON file holding a list of { name, data } objects. Import one by file, by drag and drop, or from an https URL you type in. The URL import is the only request this tool ever makes, it is only made when you ask for it, and http is refused.

Imports are checked field by field against the schema before anything is stored: a template needs a name and a data object, every key has to be one of the ten known fields, and every value has to be a string. Nothing imported is ever written to the page as markup.

Appearance

design, mode, accent
Three controls in the top bar, saved between visits. Design sets the shape language and backdrop, mode sets the lightness, and the accent can be any hue. They combine freely, and the accent is re-lit per mode so it never drops below a readable contrast.
